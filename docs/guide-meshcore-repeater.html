MCMeshCore guide

Repeater configuration

Recommended settings for MeshCore repeaters on WPAmesh. Every command should answer OK after you enter it.

Before you deploy

Coordinate first

Please talk to the coordinators before putting up a repeater. Unplanned infrastructure hurts everyone’s airtime.

Battery-powered repeater? EasySkyMesh PowerSaving firmware does wonders for battery management. See Flashing MeshCore.

Step 1: Set your regions

Don’t skip this

A repeater without regions won’t repeat scoped messages, so it breaks scoped paths through it. Set them before the repeater goes up.

Follow Setting it up in the regions guide. It takes two commands, and Why repeaters need the whole chain explains what happens without them.

Step 2: Recommended settings

Repeater CLI
  1. set loop.detect minimal
  2. set path.hash.mode 1
  3. set multi.acks 1
  4. set agc.reset.interval 4
  5. set rxdelay 3
  6. set txdelay 1
  7. set advert.interval 240
  8. set flood.advert.interval 168
SettingWhat it does
loop.detect minimalDrops flood packets that have already passed through this repeater several times
path.hash.mode 12-byte path hashes, so fewer repeaters share an ID. Caps floods at 32 hops instead of 64
multi.acks 1Turns on multi-ack support
agc.reset.interval 4Resets the radio every 4 seconds, so SX1262 boards don’t go deaf after a strong signal
rxdelay 3Weak copies of a flood wait, so the strong path forwards first and duplicates get dropped
txdelay 1A longer random wait before retransmitting a flood. Fewer collisions, a little more latency
advert.interval 240Zero-hop advert every 4 hours, the maximum
flood.advert.interval 168Flood advert once a week, the maximum
Repeaters older than 1.14

Repeaters on firmware before 1.14 silently drop messages with 2-byte paths. If you run one, update it before changing path.hash.mode anywhere.

Step 3: Change the admin password

Repeaters ship with the admin password password. Change it before the repeater goes up:

Repeater CLI
  1. password YourNewPassword

The reply echoes the new password so you can check it.

Antennas and power

Radio power plus antenna gain can’t go over about 36 dBm. The antennas and power section has the details and a quick table.
