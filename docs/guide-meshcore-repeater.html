MCMeshCore guide

Repeater configuration

Recommended settings for MeshCore repeaters on WPAmesh. Every command should answer OK after you enter it.

Before you deploy

Coordinate first

Please talk to the coordinators before putting up a repeater. Unplanned infrastructure hurts everyone’s airtime.

Battery-powered repeater? Easy SkyMesh PowerSaving firmware does wonders for battery management. See Flashing MeshCore.

Recommended settings

Repeater CLI
  1. set loop.detect minimal
  2. set path.hash.mode 1
  3. set multi.acks 1
  4. set agc.reset.interval 4
  5. set rxdelay 3
  6. set txdelay 1
  7. set advert.interval 240
  8. set flood.advert.interval 168

Region setup

This sets up the pit hierarchy and allows flood traffic for each level. North of New Castle and Grove City, use eri instead of pit (see Pit or eri?).

Repeater CLI
  1. region put us
  2. region put us-pa us
  3. region put wpa us-pa
  4. region put pit wpa
  5. region allowf *
  6. region allowf us
  7. region allowf us-pa
  8. region allowf wpa
  9. region allowf pit
  10. region save

Antennas and power

Radio power plus antenna gain can’t go over about 36 dBm. The antennas and power section has the details and a quick table.
